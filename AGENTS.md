# Repository instructions

- Use English for documentation, comments, examples, test fixtures, commit messages, and user-facing text.
- Keep VibeKeep's agent responses and generated documentation in English.
- Preserve Unicode support when changing text handling or search behavior.
- Run `npm run check` and `npm test` after changing application code.
- Repository and product language rules do not prescribe the language of development discussions; follow the user's conversation preference.
- Keep the core independent of the target language, build system, and authoring application. Treat ecosystem-specific features as adapters and distinguish planned capabilities from implemented ones.
- Do not create commits or push changes while this implementation is in progress. Keep work local until the requested functionality is complete and verified.
